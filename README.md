# Проект CashMonitor

## Описание

Проект CashMonitor - приложение на Python для анализа транзакций,
которые находятся в Excel-файле. Приложение генерирует JSON-данные для веб-страниц,
формирует Excel-отчеты, а также предоставлять другие сервисы.

### Модуль views.

1. Выполняемые модулем задачи:
- Принимает дату и время и возвращает словарь с данными о транзакциях за период
от начала месяца, на который выпадает входящая дата, по входящую дату.
2. Основная логика модуля:
- Читает EXCEL и конвертирует его в DataFrame.
- Сортирует DataFrame по дате.
- Конвертирует отфильтрованный DataFrame в JSON структуры, необходимой
для работы основной функциональности.

## Установка

1. Клонируйте репозиторий:
```commandline
git clone https://github.com/aleks-stellar/CashMonitor
```
2. Установите зависимости:
```commandline
poetry install
```
3. Создайте файл .env из копии файла .env.example в корневой директории
проекта и замените значения переменных реальными данными.

## Использование

1. Запустите модуль main в корневой директории.
2. Следуйте инструкциям.
